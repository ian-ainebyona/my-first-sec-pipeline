# Software Pipeline vs. Waterfall SDLC

**Waterfall Workflow Challenges**
* **Process Rollbacks:** When issues are encountered at late stages, the team has to go back to all previous steps.
* **Team Blockers:** When one team is blocked, other teams cannot move forward and face deadline issues.

**Software Pipeline Advantages**
* **Isolated Diffs:** Code modifications (diffs) can change parts of the application without disturbing other parts. For example, you can change the YAML file alone or change the app alone.
* **Continuous Monitoring:** Teams perform continuous monitoring to alert developers to any form of anomalies so the process can be worked on right away.
* **Automated Security:** Automation facilities provide constant and seamless security scans, forming reliable security strength.
